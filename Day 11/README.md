# Day 11 – K-Means Clustering & Principal Component Analysis (PCA)

## Overview
This project demonstrates the implementation of **K-Means Clustering** and **Principal Component Analysis (PCA)** using the Iris dataset from Scikit-learn.

## Dataset
- Iris Dataset (Built-in Scikit-learn dataset)
- 150 samples
- 4 input features
- 3 flower species

## Objectives
- Load and explore the Iris dataset.
- Apply K-Means clustering.
- Determine the optimal number of clusters using the Elbow Method.
- Visualize the clusters.
- Apply PCA to reduce the dataset to two dimensions.
- Visualize the PCA-transformed data.
- Compare clustering results with the PCA visualization.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Concepts Covered
- Unsupervised Learning
- Clustering
- K-Means Algorithm
- Elbow Method
- Principal Component Analysis (PCA)
- Data Visualization

## Results
- Successfully clustered the Iris dataset using K-Means.
- Identified the optimal number of clusters using the Elbow Method.
- Reduced the dataset from four features to two principal components using PCA.
- Visualized both clustering and PCA results.
